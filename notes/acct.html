자본유지개념 숫자 예시

기초 1,000 출자(재고 100개, 개당 10) → 기말 자본 1,500, 개당 12, 물가 10%↑

명목 재무자본: 1,500 − 1,000 = 500

불변구매력: 1,500 − 1,100 = 400

실물자본(현행원가): 1,500 − 100×12 = 300

"법적 통제가 있어야 자산" → 실질 우선, 법적 권리는 필요조건 아님(29회 46번). "수익은 출자를 포함" → 제외(33회 47번). "보고기업은 반드시 법적 실체" → 아님(37회 41번). "개념체계가 개정되면 회계기준도 자동 개정" → 아님(34회 45번). 부채의 역사적원가는 수취대가에서 거래원가를 '뺀다'(35회 41번).

매출총이익률법 (재고 추정)

매출총이익률 30% → 매출원가 = 매출 × 0.7

원가 대비 이익률 25% → 매출원가 = 매출 ÷ 1.25

기말재고 = 기초 + 매입 − 매출원가

소매재고법

원가율 = 원가 ÷ 매가

기말매가 = 판매가능매가 − 매출

기말원가 = 기말매가 × 원가율

평균: 기초 포함 / 선입선출: 기초 빼고 당기만 / 저가기준: 분모에서 순인하 제외

취득원가에 포함포함 안 함(비용)
매입가격, 매입운임·하역료·보험료, 환급 안 되는 수입관세 · 제세금 / 매입할인·리베이트는 차감비정상 낭비, 보관원가(다음 생산단계에 필요한 보관은 제외), 관리간접원가, 판매원가, 환급받는 부가가치세(32회 55번)

"NRV는 시장참여자 사이 정상거래 가격 − 처분부대원가라 기업 특유 가치가 아니다" → 공정가치 정의로 바꿔치기(37회 43번). 저가법은 항목별이 원칙, 유사 항목은 조별 가능, 총계기준 불가(37회 45번). 평가손실 환입은 최초 장부금액 한도, 매출원가에서 차감. 중개·가격차익 목적 상품(브로커-트레이더)의 순공정가치 변동은 기타포괄손익이 아니라 당기손익(29회 67번). 기말재고 과대계상 → 당기 이익 과대, 다음 해 이익 과소(2년 뒤 자동 상쇄, 35회 48번).
버려도 되는 주제저가기준 선입선출 소매재고법처럼 변형을 겹친 문제(28회 66번 · 29회 66번)는 과락 회피 목표라면 넘긴다. 원가율 기본 공식 2개(평균·선입선출)만 확실히. 재고 평가방법 변경의 소급 계산(29회 68번 · 32회 67번)은 22단원(회계변경)에서 다시 본다.

복구원가 숫자 예시

설비 10,000 · 5년 · 잔존 0 · 정액. 5년 뒤 복구비 3,000, 할인율 10% (5년 현가계수 0.6209)

  1. 복구충당부채 = 3,000 × 0.6209 = 1,863 → 설비 원가 = 10,000 + 1,863 = 11,863
  2. 1년차 감가상각비 = 11,863 ÷ 5 = 2,373
  3. 1년차 이자비용(충당부채 증가) = 1,863 × 10% = 186
  4. 1년차 당기비용 합계 = 2,373 + 186 = 2,559
  5. 5년 뒤 실제 복구비 ≠ 3,000이면 차액은 복구공사손익
자주 틀리는 지점 토지 가치가 올라도 건물 감가상각대상금액은 변하지 않는다(28회 57번). 토지는 상각 X. 복구원가 문제에서 '당기비용'을 물으면 감가상각비 + 이자비용 둘 다(31회 47번 · 37회 48번). 감가상각비만 쓰고 끝내는 실수가 가장 많다. 가동 중단 기간에도 정액법이면 상각한다(34회 65번). 월할 상각이면 취득 월부터 센다. 정부보조금 받은 연도 순이익 영향 = −(감가상각비 − 보조금 상계액)(28회 47번 · 36회 46번).
버려도 되는 주제무이자 차입·공채 강제매입처럼 현재가치로 원가를 다시 구하는 문제(31회 57번 · 31회 68번 · 32회 56번)는 금융자산·금융부채(12~13단원)를 배운 뒤로 미룬다.

손상 숫자 예시 (원가모형)

기계 5,000 · 5년 · 잔존 0 · 정액. 1년 말 장부 4,000, 순공정가치 2,700 · 사용가치 3,000. 2년 말 회수가능액 3,500

  1. 1년 말 회수가능액 = max(2,700, 3,000) = 3,000 → 손상차손 4,000 − 3,000 = 1,000
  2. 2년차 감가상각비 = 3,000 ÷ 남은 4년 = 750 → 2년 말 장부 2,250
  3. 환입 한도 = 손상 안 했으면 2년 말 장부 = 5,000 − 1,000×2 = 3,000
  4. 회수가능액 3,500이지만 한도 3,000까지만 → 환입 = 3,000 − 2,250 = 750 (당기이익)

차입원가 자본화

비중 중 · 6문항8단원
짓는 데 오래 걸리는 자산(적격자산)에 쓴 돈의 이자는 비용이 아니라 자산 원가에 넣는다. 특정차입금 먼저, 남은 지출은 일반차입금 이자율로.공식 하나로 매번 같은 형태가 나온다 → 과락 회피용 가성비 최고 단원. 버리지 말 것.

시험에서 묻는 방식 · "20×1년에 자본화할 차입원가는?" 계산 1문항. 사업 착공·완공 시점과 지출 일자가 표로 주어진다

  1. 연평균지출액 = Σ 지출액 × (그해 자본화 기간 중 남은 개월 ÷ 12). 정부보조금으로 낸 지출은 빼고 계산(36회 45번)
  2. 특정차입금 자본화 = 차입액 × 이자율 × 기간 − 일시투자수익
  3. 자본화이자율 = 일반차입금 이자비용 합계 ÷ 일반차입금 연평균액
  4. 일반차입금 자본화 = (연평균지출액 − 특정차입금 연평균 사용액) × 자본화이자율. 한도 = 일반차입금 실제 이자비용
  5. 2 + 4 = 자본화할 차입원가

개발비 숫자 예시

  1. 20×1 비용 = 연구 500 + 요건 충족 전 개발 300 = 800
  2. 개발비(자산) = 500 (요건 충족 후 지출만)
