탄력성

비중 상 · 13문항 · 최빈출6~7강
탄력성 = 가격이 1% 변할 때 수요량이 몇 % 변하나. 판매수입(총수입)은 "탄력적이면 가격 내릴 때, 비탄력적이면 가격 올릴 때" 늘어난다.직선 수요곡선은 위쪽 절반이 탄력적, 중점이 1, 아래쪽 절반이 비탄력적. 판매수입 최대 = 중점.

가격상한 (최고가격제)

무차별곡선 · 예산선 · 소비자균형

예산선

절편 = 소득 ÷ 그 재화 가격, 기울기 = PX/PY

  1. MUX, MUY를 구해(편미분) MRS = MUX/MUY

가격효과 · 대체효과 · 소득효과 · 기펜재

소비자이론 응용

비중 중 · 9문항17~18강
새 이론이 아니라 소비자균형에 재화 이름만 바꾼 것이다. 여가 = X재(가격은 임금), 1기 소비·2기 소비 = X재·Y재(2기 소비의 가격은 1/(1+r)).

노동-여가 · 후방굴절 노동공급

임금↑ → 대체효과: 여가가 비싸져 노동↑ / 소득효과: 부자가 되어 여가(정상재)↑ → 노동↓. 소득효과 > 대체효과이면 노동 감소(후방굴절).

시점간 선택

예산: c1 + c2/(1+r) = y1 + y2/(1+r)

평생소득 현재가치를 먼저 구한 뒤 콥-더글러스 지출비중으로 나눈다(29회 55번: 3,000 + 3,300/1.1 = 6,000 → c1 = 2,000 → 1,000 저축).

이자율↑: 대체효과는 현재소비↓. 저축자는 소득효과가 현재소비↑, 차입자는 ↓.

현시선호

"A를 고를 때 B도 살 수 있었다" → A가 B보다 현시선호.

풀이: 가격 × 묶음 비용표를 만들어 '고른 묶음 비용 이하'인 묶음 표시. 약공리 위배 = 두 묶음이 서로를 현시선호(31회 54번, 33회 55번).

실물부존 (X재를 파는 사람)

X 가격↑ → 가진 X의 값이 올라 부자가 됨(부존소득효과). 일반 소비자와 소득효과 방향이 반대.

파는 재화 값이 내렸는데 효용이 늘었다면 구매자로 바뀐 것(36회 42번).
