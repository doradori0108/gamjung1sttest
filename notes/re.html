계산 1 — 기대수익률 · 분산 (28회 93번)

  1. 기대수익률 = Σ(확률 × 수익률) = 0.3×20 + 0.4×30 + 0.3×40 = 30%
  2. 분산 = Σ 확률 × (수익률 − 기대)² = 0.3×0.01 + 0.4×0 + 0.3×0.01 = 0.006
  3. 표준편차 = √분산 ≈ 7.7% · 변동계수 = 표준편차 ÷ 기대수익률 ≈ 0.26 (작을수록 위험 대비 효율적)

계산 2 — 레버리지 (35회 118번)

  1. 총투자수익률 = (NOI 500 + 가격상승 200) ÷ 10,000 = 7% → 대출 없을 때 자기자본수익률 7%
  2. 대출 40% = 4,000만, 이자 4% = 160 → 자기자본 6,000
  3. 자기자본수익률 = (500 + 200 − 160) ÷ 6,000 = 9%
  4. 판정: 총투자수익률 7% > 이자율 4% → 정(+)의 레버리지(지분수익률 > 총투자수익률)
자주 틀리는 지점 요구수익률↑ → 가치↑ → 가치↓(28회 90번 ④). 요구수익률 = 최대·시간 고려 X → 최소·시간 고려(30회 88번 ㄱ). 기대 > 요구면 기대수익률 상승 / 요구수익률 하락 → 기대수익률 하락(30회 88번 ㄷ, 36회 97번 ③). 분산투자로 체계적 위험 감소 → 비체계적만(35회 111번 ①). 효율적 투자선 우하향 → 우상향(29회 94번 ②). 무위험률이 개인 위험혐오도로 결정 → 위험할증률이 그렇다(31회 111번 ③). 정(+) 레버리지 = 총투자 − 지분 > 0 → 지분 − 총투자 > 0(30회 87번 ①).
우선순위두 계산은 반드시 손으로 풀어 볼 것. 포트폴리오 최소분산 비중 공식·공분산 계산(37회 103번 유형)은 시간 대비 효율이 낮으니 1차에선 결론(상관계수 효과)만 챙기고 버려도 된다.
