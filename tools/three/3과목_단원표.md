# 1차 나머지 3과목 단원표 (민법 · 부동산학원론 · 감정평가관계법규)

작성 2026-11-21(같은 날 10개년으로 갱신). 아직 앱에 넣지 않은 초안. 회계·경제처럼 단원 코드(u) → 기출 분류 → 진도 제한 출제에 그대로 쓸 수 있게 정리함.

- 문항 수 = 10개년(28~37회, 과목당 400문항)을 문항별로 분류한 값. 28~31·35~37회는 받은 시험지 텍스트, 32~34회는 시험지 이미지(32·33회 부동산학원론)와 공개 기출 텍스트(0gichul.com) 기준. 2026-11-21 10개년으로 갱신(처음엔 7개년).
- 비중: 연평균 3문항 이상 = 상, 1.5~3 = 중, 1.5 미만 = 하.
- 단원 순서는 표준 기본서 순서. 수강할 강의(민법 백운정, 부동산학 국승옥, 관계법규 도승하)의 강 번호는 강의 목차를 받은 뒤 lec에 맞춰 넣는다. 강사 교재와 단원 이름·순서가 다를 수 있음.
- 민법·부동산학 분류는 문제 첫 줄로 판단해서 사례형 문항 몇 개는 ±1 정도 어긋날 수 있음. 관계법규는 법률별 배정이 매년 고정이라 정확함.

## 다음 단계(앱 반영 때)
1. 각 강의 목차(강 번호)를 받아 단원별 lec 매핑
2. 32~34회 문제 원문 확보(이미지 판독) + 3과목 정답표 대조 — 단원 분류는 10개년 완료
3. 회계·경제와 같은 방식으로 기출 · 오늘의 문장 · 개념정리를 수강 순서대로 배치 구축
4. 3과목 이상이 되면 '오늘의 문제' 총량 방식(하루 총량 고정 / 요일별 순환) 결정
