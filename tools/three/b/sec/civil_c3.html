물건 · 주물과 종물 · 과실

비중 하 · 9문항4단원
매년 1문항(7~9번). 종물 요건 3가지, 과실 2종류, 토지·건물 개수 기준만 알면 된다.부동산학원론 R1(정착물·명인방법)과 겹치는 단원 — 함께 보면 두 과목이 한 번에 정리된다.

시험에서 묻는 방식 · "물건에 관한 설명으로 옳지 않은 것은?" 한 문제에 종물 · 과실 · 집합물 · 토지/건물 개수 · 명인방법 지문이 섞여 나온다.

개수 기준

토지 = 지적공부의 필 · 분할절차 없는 분필등기 = 무효. 건물 = 물리적 구조 + 건축자 의사. 구분소유 = 구조상·이용상 독립성 + 구분행위. 집합물 = 원칙적으로 여러 물건(특정되면 양도담보 가능).

자주 틀리는 지점 천연과실 귀속은 특약으로도 못 바꾼다 → 특약 가능(28회 7번 ④). 종물 = 주물 "소유자"의 상용 → 주물 자체의 상용(31회 7번 ①, 37회 8번 ④). 부동산은 종물 X → O(37회 8번 ③). 집합물은 원칙적으로 하나의 물건 → X(30회 9번 ⑤). 구분행위 없어도 독립성만 있으면 구분소유권 → 구분행위 필요(36회 9번 ①). 토지전세권의 과실 = 설정자 → 전세권자(29회 7번 ㄹ). 입장료 = 과실 → X(37회 8번 ①).
우선순위비중 하. 종물 구조도와 과실 표만. 관리할 수 있는 자연력(동산) · 금전의 물건성 같은 이론 논점은 버려도 된다.
