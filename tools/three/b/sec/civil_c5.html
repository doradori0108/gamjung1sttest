효력발생 — 도달주의(제111조)

도달 = 상대방이 알 수 있는 상태(실제로 읽을 필요 X). 발송 후 사망·제한능력이 되어도 효력 영향 X. 내용증명·등기우편 = 그 무렵 도달 추정. 상대방이 제한능력자면 대항 X → 법정대리인이 안 후엔 대항 O(제112조). 과실 없이 상대방·소재를 모르면 공시송달.

자주 틀리는 지점 비진의 무효 주장 시 상대방이 선의·무과실 증명 → 표의자가 상대 악의·과실 증명(29회 9번 ⑤). 파산관재인은 제3자 X → O(28회 10번 ①). 제3자는 선의·무과실 → 선의면 족함(37회 11번 ㄱ, 31회 13번 ⑤). 강제집행 면탈 허위근저당 = 반사회질서 → 통정허위표시(30회 11번 ②). 착오를 상대가 알고 이용해도 중과실이면 취소 X → 취소 O(35회 10번 ⑤). 해제되면 착오 취소권 소멸 → 취소 가능(37회 12번 ③). 법률의 착오엔 적용 X → 적용(31회 12번 ④). 상대방 대리인의 강박 = 제3자 강박 → X(36회 10번 ㄱ). 제3자가 선의를 증명 → 선의 추정(ㄴ). 법정대리인이 안 후에도 대항 X → 대항 O(28회 11번 ②).
우선순위비교표 · 제3자 O/X 표 · 사기 관계도 세 개가 핵심. 의사표시 이론(의사주의·표시주의·효과의사 구조)과 동기의 착오 학설은 판례 결론("상대방이 유발한 동기 착오는 표시 없어도 중요부분 가능")만 외우고 버린다.
