기간 계산(제155~161조)

시·분·초 = 즉시 · 일·주·월·연 = 초일 불산입(오전 0시 시작이면 산입), 말일 종료로 만료 · 월·연 중간부터 기산하면 최후 월·연의 기산일에 해당한 날의 전일 만료 · 연령은 출생일 산입 · 말일이 토요일·공휴일이면 다음 날.

자주 틀리는 지점 판결 확정 단기채권 5년 → 10년(29회 16번 ①). 부당이득 = 안 때 → 발생 시(35회 18번 ②). 채무불이행 손해배상 = 청구 시 → 불이행 시(31회 18번 ②). 정지조건 미성취에도 진행 → X(36회 18번 ②). 응소 = 소 제기 시 중단 → 응소 시(35회 19번 ①). 물상보증인 소송 응소 = 중단 → X(28회 20번, 37회 20번 ㄷ). 유치권 부동산 매수인 원용 X → O(29회 17번 ③). 일반채권자 원용 → X(31회 19번 ③). 시효이익 미리 포기 가능 → X(30회 19번 ②). 완성 후 승인 = 포기로 "보아야" → 추정(37회 19번 ②).
우선순위4칸 표 + 기산점 표 + 제척기간 비교표. 단기시효 채권 목록 전부(제163·164조)는 대표 예(이자·사용료·공사·숙박음식)만 외우고 나머지는 버린다. 시효정지 사유 세부도 후순위.
