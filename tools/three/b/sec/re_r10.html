부동산금융 (대출 · 상환방식 · 증권화 · PF · 리츠 · 주택연금)

비중 상 · 43문항9단원
부원론에서 출제량 2위 단원. "누가 위험을 지나"(고정·변동금리, MPTS·MBB) 와 "초기에 원금을 얼마나 갚나"(상환방식) 두 축으로 정리한다.매년 4~5문항. 상환액 계산 1문항 + 증권 1문항 + PF·리츠·주택연금 중 1~2문항.

시험에서 묻는 방식 · 고정/변동금리 위험 · 상환방식 비교·계산(첫 회 원금·원리금, 잔금) · 듀레이션 순서 · MPTS/MBB/MPTB/CMO 위험 귀속 · PF 특징 · 리츠 법령 숫자 · 주택연금 · 지분 vs 부채금융 · LTV·DCR 계산

원금균등(CAM)원리금균등(CPM)체증식(GPM)만기일시
매기 상환액원금 고정 → 원리금 감소원리금 고정(대출액 × 저당상수) · 이자 비중 ↓점점 증가 · 초기 부(−)상환 가능이자만 → 만기 원금
초기 부담가장 큼중간작음 → 소득 증가 예상자가장 작음
듀레이션원금균등 < 원리금균등 < 체증식 < 만기일시 (초기 원금 회수가 많을수록 짧다)
총 이자원금균등이 가장 적다(원금을 빨리 줄이므로)
  1. 원금균등 1회차 원금 = 대출액 ÷ 기간 · 이자 = 잔금 × 이자율
  2. 원리금균등 1회차 원리금 = 대출액 × 저당상수 · 그중 이자 = 대출액 × 이자율 · 원금 = 나머지
  3. n년 후 잔금(원리금균등) = 원리금 × 남은 기간의 연금현가계수
  4. LTV(35회 106번): 부채서비스 = NOI ÷ DCR = 2천만 → 대출 = 2천만 ÷ 저당상수 0.1 = 2억 → LTV = 2억 ÷ 4억 = 50%

PF(프로젝트 파이낸싱)

사업 현금흐름 기반 · SPC 설립 · 사업주 = 비소구·제한적 소구 + 부외금융 · 금융기관 = 높은 금리·수수료, 에스크로·책임준공 등으로 위험 관리 · 공통 단점 = 복잡한 계약.

리츠 · 주택연금

리츠 = 간접투자 · 자기관리(직접 운용, 최저자본금 70억) / 위탁관리·CR리츠(50억) · 총자산 80% 부동산 등, 70% 부동산 · 회계 = 금융위원회 기준.

주택연금 = 장수·주택가격 하락 위험 공사 부담 · 나이 많고 집값 높을수록 월지급금↑ · 가입 후 집값 변동과 무관.

지분금융 = 리츠·부동산펀드·조인트벤처·신디케이트·공모주 / 부채금융 = 저당대출·MBS·ABCP·회사채 / 메자닌 = 전환사채·신주인수권부사채·후순위대출. 리츠·주택연금 숫자 기준은 개정이 잦아 교재 최신판 확인.

자주 틀리는 지점 원리금균등 듀레이션이 원금균등보다 짧다 → 원금균등이 가장 짧다(31회 104번 ③, 36회 100번 ①). 체증식은 소득 감소 예상자에게 → 증가 예상자(31회 104번 ④). MBB 위험이 투자자에게 이전 → 발행자 보유(30회 94번 ②, 31회 102번 ③). 부외금융은 금융기관 장점 → 사업주(31회 103번 ③). 리츠 = 직접투자 → 간접(37회 105번 ①). ABCP = 지분금융 → 부채금융(37회 110번). 주택연금 집값 하락 위험 = 가입자 → 공사(37회 109번 ①).
우선순위상환방식·증권 표 두 개는 필수. 계수를 쓰는 잔금·승계권 가치 계산(36회 101번 유형)은 공식만 익히고 시간이 없으면 넘긴다. 한국주택금융공사법 세부(보증기금 용도 등)는 기출 지문만.
