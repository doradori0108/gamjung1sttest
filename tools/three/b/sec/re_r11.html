개발 위험 3종

워포드 7단계

구상 → 예비적 타당성 → 부지 확보 → 타당성 분석 → 금융 → 건설 → 마케팅. "개발여건·잠재력 분석으로 개발방향 설정" = 예비적 타당성 분석 단계.

마케팅 3전략

시장점유: STP(세분화 → 표적 → 포지셔닝) + 4P Mix(제품·가격·유통·촉진). 세분시장은 마케팅 믹스에 서로 다르게 반응해야.

고객점유: AIDA(주목 → 관심 → 욕망 → 행동).

관계마케팅: 장기적 관계.

부동산신탁 4종

관리신탁(해외교포·고령자) · 처분신탁(대형·고가 처분) · 담보신탁(수익권증서로 대출, 공매가 경매보다 간편·신속) · 개발(토지)신탁(신탁회사가 개발). 신탁재산은 수탁자 고유재산과 독립 → 강제집행 배제.

자주 틀리는 지점 환지방식 = 초기 비용 크고 저항 심함 → 수용방식(28회 117번). 초등학교 = BTO → BTL(30회 111번 ④). BTO 운영 책임 = 공공 → 민간(37회 112번 ㄱ). 후분양 = 시장위험 감소 → 증가(31회 100번 ⑤). 인허가 불확실성 = 시장위험 → 법률적 위험(30회 113번). 위탁관리 = 기밀유지 장점 → 자기관리(30회 112번 ⑤, 35회 117번 ⑤). 혼합관리 책임소재 명확 → 불분명(31회 99번 ⑤). AIDA 순서 행동부터 → 주목부터(36회 103번 ⑤). 시장점유전략 = AIDA → 고객점유(28회 115번 ②). 담보신탁 환가가 경매보다 복잡 → 간편(37회 120번 ⑤).
우선순위표 5개만 확실히 하면 4~5문항 중 3문항 이상. 부동산개발업법 세부(개발업 등록 요건, 31회 101번 유형)와 정비사업 종류(빈집법·소규모주택정비)는 해마다 소재가 달라 기출 지문만.
