부동산투자론 (수익률 · 위험 · 포트폴리오 · 레버리지)

비중 중 · 22문항7단원
"기대 vs 요구수익률", "체계적 vs 비체계적 위험", "총투자 vs 지분수익률" 세 쌍의 비교로 거의 모든 문제가 풀린다.매년 2문항. 기대수익률·분산 계산, 레버리지 자기자본수익률 계산이 번갈아 나온다. 재무관리의 기초라 2차 실무 수익환원법의 바탕.

시험에서 묻는 방식 · 수익률 3종 O·X · 위험과 요구수익률 · 포트폴리오(상관계수·효율적 투자선·최적 포트폴리오) · 기대수익률·분산·변동계수 계산 · 레버리지 판정·계산

수익률뜻포인트
기대수익률예상 수입·지출로 계산한 사전(ex-ante) 수익률확률 가중평균
요구수익률투자에 필요한 최소 수익률 = 무위험률 + 위험할증률할인율 역할 · ↑이면 가치↓ · 체계적 위험↑이면 ↑
실현수익률투자 후 실제 달성(사후·역사적)—
기대 > 요구→수요↑ · 가격↑→기대수익률↓→기대 = 요구(균형)

계산 1 — 기대수익률 · 분산 (28회 93번)

  1. 기대수익률 = Σ(확률 × 수익률) = 0.3×20 + 0.4×30 + 0.3×40 = 30%
  2. 분산 = Σ 확률 × (수익률 − 기대)² = 0.3×0.01 + 0.4×0 + 0.3×0.01 = 0.006
  3. 표준편차 = √분산 ≈ 7.7% · 변동계수 = 표준편차 ÷ 기대수익률 ≈ 0.26 (작을수록 위험 대비 효율적)

위험 — 분산투자로 지울 수 있나

체계적 위험비체계적 위험
원인경기·금리·인플레(시장 전체)개별 부동산 고유(공실·임차인)
분산투자제거 불가 → 위험할증 요구제거 가능

포트폴리오

상관계수 −1 → 분산효과 최대(무위험 포트폴리오 가능) · +1 → 분산효과 없음. 효율적 투자선 = 우상향. 최적 포트폴리오 = 효율적 투자선 × 무차별곡선 접점. 위험회피형은 같은 수익이면 낮은 위험(평균-분산 지배원리).

투자자 유형

위험회피형: 위험↑ 보상 요구 · 위험중립형: 기대수익률만 봄 · 위험선호형: 위험 자체를 즐김. 요구수익률의 무위험률은 시장이 정하고, 위험할증률이 개인마다 다르다.

계산 2 — 레버리지 (35회 118번)

  1. 총투자수익률 = (NOI 500 + 가격상승 200) ÷ 10,000 = 7% → 대출 없을 때 자기자본수익률 7%
  2. 대출 40% = 4,000만, 이자 4% = 160 → 자기자본 6,000
  3. 자기자본수익률 = (500 + 200 − 160) ÷ 6,000 = 9%
  4. 판정: 총투자수익률 7% > 이자율 4% → 정(+)의 레버리지(지분수익률 > 총투자수익률)
자주 틀리는 지점 요구수익률↑ → 가치↑ → 가치↓(28회 90번 ④). 요구수익률 = 최대·시간 고려 X → 최소·시간 고려(30회 88번 ㄱ). 기대 > 요구면 기대수익률 상승 / 요구수익률 하락 → 기대수익률 하락(30회 88번 ㄷ, 36회 97번 ③). 분산투자로 체계적 위험 감소 → 비체계적만(35회 111번 ①). 효율적 투자선 우하향 → 우상향(29회 94번 ②). 무위험률이 개인 위험혐오도로 결정 → 위험할증률이 그렇다(31회 111번 ③). 정(+) 레버리지 = 총투자 − 지분 > 0 → 지분 − 총투자 > 0(30회 87번 ①).
우선순위두 계산은 반드시 손으로 풀어 볼 것. 포트폴리오 최소분산 비중 공식·공분산 계산(37회 103번 유형)은 시간 대비 효율이 낮으니 1차에선 결론(상관계수 효과)만 챙기고 버려도 된다.
