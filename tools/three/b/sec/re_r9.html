자주 틀리는 지점 NPV가 "1"보다 크면 투자 → NPV 기준은 0, 1은 PI(30회 92번 ⑤). 승수가 클수록 좋음 → 작을수록(31회 108번 ①, 37회 104번 ④). 두 투자안 IRR은 더해진다 → NPV만 가치가산(35회 116번 ②). 목표액 적립 = 연금의 미래가치계수 → 감채기금계수(31회 110번 ⑤). 회계적수익률법은 시간가치 고려 → X(31회 97번).
우선순위사다리·6계수·판단 기준표는 반드시. 계수를 이용한 긴 계산(37회 108번 연금 비교 유형)은 1차에선 시간이 많이 들면 넘기고 마지막에 푼다. IRR 복수해·재투자 가정의 이론적 배경은 결론만.
